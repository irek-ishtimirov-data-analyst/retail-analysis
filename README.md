# Проект по анализу тороговой сети.
## Цель проекта:
Выявить операционные аномалии, оценить влияние роста транзакций через кассы самообслуживания на среднюю длительность операций.
## Методы анализа:
— Провёл анализ данных по транзакциям сети розничных магазинов.\
— Проанализировал нагрузку на серверы и зафиксировал критический пик на одном из них.\
— Изучил длительность операций и выявил аномальные задержки, интерпретировал их с учётом бизнес-контекста.

## Используемые инструменты:
Excel, функция QUERY, Power Pivot, сводные таблицы, визуализации (графики).

## Результат:
Подготовлен аналитический отчет, демонстрирующий влияние резкого притока транзакций на перегрузку серверов и причины замедления обработки платежей на кассах самообслуживания. На основе выводов внедрены рекомендации по оптимизации нагрузки на серверы и улучшению интерфейса касс.
