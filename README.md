# Проект по анализу тороговой сети:
## Цель проекта:
Выявить операционные аномалии, оценить влияние роста транзакций через кассы самообслуживания на среднюю длительность операций.
## Методы анализа:
— Провёл анализ данных по транзакциям сети розничных магазинов.\
— Проанализировал нагрузку на сервера и зафиксировал пиковое значение на одном из них.\
— Изучил длительность операций и выявил аномальные значения, интерпретировал их с учётом бизнес-контекста.

## Используемые инструменты:
Excel, функция QUERY, Power Pivot, сводные таблицы, визуализации (графики).

## Результат:
Подготовлен аналитический отчёт, демонстрирующий влияние увеличения количества транзакций на работу серверов и роста количества транзакций через кассы самообслуживания на среднее время обработки платежей.
